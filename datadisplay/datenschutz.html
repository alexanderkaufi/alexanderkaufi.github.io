Besuch der Website und Hosting

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet der Hosting-Dienst technische Verbindungsdaten. GitHub informiert darüber, dass die IP-Adresse von Besuchern zum Schutz und zur Sicherheit des Dienstes protokolliert und gespeichert wird. Dazu können weitere Angaben zur angeforderten Seite und zur Verbindung gehören.

Die Verarbeitung dient der technischen Auslieferung, dem sicheren Betrieb und der Abwehr von Störungen. Soweit wir dafür verantwortlich sind, stützen wir sie auf unser berechtigtes Interesse am Betrieb einer sicheren und erreichbaren Website (Art. 6 Abs. 1 lit. f DSGVO). GitHub beschreibt seine eigene Datenverarbeitung und die Dauer der Speicherung in der Datenschutzerklärung von GitHub sowie in der Dokumentation zu GitHub Pages und Besucherdaten.

GitHub kann personenbezogene Daten auch an Orten außerhalb des Europäischen Wirtschaftsraums verarbeiten. Informationen zu internationalen Übermittlungen und den dabei verwendeten Schutzmaßnahmen findest du in GitHubs Angaben zu internationalen Datenübermittlungen.

Darstellung der Website

Wenn du im Farbschalter „Hell“ oder „Dunkel“ auswählst, speichert dein Browser diese Wahl im lokalen Speicher deines Geräts, damit sie beim nächsten Besuch wieder gilt. Wählst du „System“, wird die gespeicherte Auswahl gelöscht und die Website folgt der Darstellungseinstellung deines Geräts. Damit kannst du die Speicherung deiner manuellen Auswahl jederzeit rückgängig machen. Die Einstellung wird nicht an uns übertragen.

Die Website setzt selbst keine Cookies und verwendet keine Reichweitenmessung oder Werbeverfolgung.

Wir speichern die Korrespondenz so lange, wie sie für die Bearbeitung erforderlich ist, und beachten gesetzliche Aufbewahrungspflichten.
